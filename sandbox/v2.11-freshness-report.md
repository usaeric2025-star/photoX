# v2.11 Data Freshness Contract Report

## Policy Mappings

1. **REALTIME**
   - Use for highly dynamic data that updates frequently.
   - Example: Photo lists, infinite scroll photo feeds.
   - Code:
     ```ts
     import { createStaleTime } from '@/shared/freshnessSchema';
     
     useQuery({
       queryKey: ...,
       queryFn: ...,
       staleTime: createStaleTime('REALTIME'), // 0ms
     });
     ```

2. **STABLE**
   - Use for moderately stable data like user configuration or groups info.
   - Example: Global user config, albums
   - Code:
     ```ts
     import { createStaleTime } from '@/shared/freshnessSchema';
     
     useQuery({
       queryKey: ...,
       queryFn: ...,
       staleTime: createStaleTime('STABLE'), // 5 minutes
     });
     ```

3. **ARCHIVE**
   - Use for data that rarely changes.
   - Example: Statistics, unchangeable system settings
   - Code:
     ```ts
     import { createStaleTime } from '@/shared/freshnessSchema';
     
     useQuery({
       queryKey: ...,
       queryFn: ...,
       staleTime: createStaleTime('ARCHIVE'), // 1 hour
     });
     ```
